Isambard AI Skills

A curated collection of agent skills for working with Isambard HPC systems — designed for use with Claude Code and other AI coding tools.

What are Skills?

Agent skills are plain-text instruction files (usually Markdown) that teach AI coding assistants how to perform specific tasks in your environment. When a skill is loaded into a tool like Claude Code, the agent reads the instructions and uses them to answer questions, write scripts, and run commands correctly for that environment.

Skills hosted here cover Isambard-specific workflows such as submitting and managing HPC jobs. Each skill is a single file served directly from this site so that the URLs remain stable regardless of where the underlying repository is hosted.

For full Isambard documentation visit docs.isambard.ac.uk.

Add the Isambard marketplace so Claude Code can browse and install all available skills: 

/plugin marketplace add https://skills.isambard.ac.uk/.claude-plugin/marketplace.json

Then install a specific skill by name: 

/plugin install slurm@isambard-skills

Or enable a skill automatically for a project by adding this to your project's .claude/settings.json: 

{
  "extraKnownMarketplaces": {
    "isambard-skills": {
      "source": {
        "source": "url",
        "url": "https://skills.isambard.ac.uk/.claude-plugin/marketplace.json"
      }
    }
  },
  "enabledPlugins": {
    "slurm@isambard-skills": true
  }
}

Other Agent Tools

For other agent-based coding tools, paste the skill URL into the tool's context or skill configuration. Skill files are served directly from this site as plain Markdown.

Skill URLs follow the pattern: 

https://skills.isambard.ac.uk/skills/<name>/SKILL.md
More information on using skills with specific tools can be found in the Isambard documentation.
